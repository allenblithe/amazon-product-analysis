# Amazon 商品运营分析项目

> **作者**：钱陶勇 ｜ 2027届统计学 ｜ 阜阳师范大学
> **类型**：个人数据分析项目（第二个项目）
> **数据**：1000 个 Amazon 真实商品（55 个字段，含价格、评分、评论、BSR 排名等）

---

## 一、项目背景

在跨境电商运营实习中，我负责 Amazon / eBay 双平台的商品上架与优化。
实习中最大的困惑是：**为什么有些商品排名靠前、出单快，有些怎么优化都没起色？**

带着这个问题，我用公开数据做了一次系统分析：
**什么因素真正影响 Amazon 商品的排名（BSR）？**

---

| 项 | 内容 |
|---|---|

## 三、分析方法（4 个模块）

### 模块 1：市场概览
- 一级类目分布、价格分布
- **发现**：类目集中在 Clothing/Shoes/Jewelry（21.6%），价格中位数 $28.99

### 模块 2：什么因素影响排名（BSR）？
- 用 **Spearman 秩相关**（对排名这种非正态分布更稳健）
- 分箱对比：评论数 / 评分 / 视频 / A+ 内容

### 模块 3：爆款特征画像
- 定义爆款：BSR 前 20%（≤7135）
- 对比爆款 vs 普通商品的中位数差异

### 模块 4：运营优化建议
- 价格带表现、折扣效果、Listing 完善度

---

## 四、关键发现

### 🔑 发现 1：评论数是最强的排名因素

```
评论数 vs BSR 的 Spearman 相关系数：-0.51（中等偏强负相关）
爆款商品评论数 = 普通商品的 11.7 倍
```

**解读**：评论数越多 → 排名越靠前。评论数本质是"销量 + 评价积累"的代理指标。

### 🔑 发现 2：评分有门槛效应

```
评分 < 4.0 → BSR 中位数 78,000+
评分 4.5-4.7 → BSR 中位数 28,000
评分 4.7+ → BSR 中位数 19,000
```

**解读**：评分从 4.0 提到 4.5，排名改善最明显；4.5 以上继续提升但边际递减。

### 🔑 发现 3：Listing 完善度显著影响排名

| 指标 | 有 | 无 | 差异 |
|---|---|---|---|
| **视频** | BSR 33,317 | 41,100 | 好 19% |
| **A+ 内容** | BSR 36,744 | 64,212 | **好 43%** |

**解读**：A+ 内容（图文详情页）是性价比最高的优化项——成本低、效果明显。

### 🔑 发现 4：价格带 $15-25 表现最好

```
价格带 $15-25 的商品 BSR 中位数最低（表现最好）
极低价（<$15）和极高价（$100+）表现较差
```

## 五、给运营的可执行建议

| # | 建议 | 依据 |
|---|---|---|
| 1 | **优先积累评论**（测评、Vine 计划、售后引导） | 评论数与排名强相关（-0.51） |
| 2 | **评分守住 4.5** | 4.5 是排名改善的关键门槛 |
| 3 | **全量配 A+ 内容** | A+ 商品 BSR 好 43%（成本最低的优化） |
| 4 | **主推商品加视频** | 有视频 BSR 好 19% |
| 5 | **选品聚焦 $15-25 价格带** | 该价格带排名表现最好 |

## 六、面试怎么讲（1 分钟版）

```
"我在跨境电商实习时发现，有些商品怎么优化都起不来。
所以我用 1000 个 Amazon 真实商品数据做了一次分析：
什么因素真正影响商品排名（BSR）？

我的发现是：
第一，评论数是最强的排名因素（相关系数 -0.51），爆款的评论数是普通商品的 11.7 倍；
第二，评分有门槛效应——从 4.0 提到 4.5，排名改善最明显；
第三，A+ 内容对排名的影响被低估了——有 A+ 的商品 BSR 好 43%，而且成本最低。

这个分析让我意识到：运营优化要有优先级——
先补 A+ 内容（低成本）+ 积累评论（长期壁垒），而不是盲目改标题。"
```
